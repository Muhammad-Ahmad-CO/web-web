# found — the curiosity cabinet

A personal archive of the wonderfully random, rebuilt from Instagram reel
[DfHyZQoIH_U](https://www.instagram.com/reel/DfHyZQoIH_U/) (by design4me__).

A royal-blue page with a giant cream "found", taped polaroid cards, corner
webs — and a canvas spider that chases your cursor (which is a fly), pounces
when you click, and sleeps when the mouse stops.

Open `index.html` or visit the GitHub Pages deployment. No build step, no
dependencies — one self-contained page.
